# tAge: tAge – Transcriptomic Biological Age Analysis Package

tAge provides API for Gladyshev Lab transcriptomic clock use. The
package implements preprocessing pipelines, age prediction using Elastic
Net and Bayesian Ridge models, and comprehensive visualization tools for
transcriptomic age analysis.
