# Load gene list

Loads the gene list included with the tAge package.

## Usage

``` r
load_gene_list()
```

## Value

A character vector of gene identifiers.

## Examples

``` r
gene_list <- load_gene_list()
head(gene_list)
#> [1] "100009600" "100012"    "100017"    "100019"    "100034251" "100034748"
```
